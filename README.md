# Vivek Thapar — Personal Portfolio & Executive Redesign (Vue.js 3 + Vue Router + Vite)

A modern, high-performance executive personal branding, multi-page portfolio, and thought leadership platform for **Vivek Thapar** (Serial Entrepreneur, Digital Growth Strategist, and Founder & CEO of Mirch Media NYC).

Built with **Vue.js 3**, **Vue Router 4**, **Vite 6**, **Tailwind CSS**, and **Lucide Icons**.

## 🛠️ Tech Stack & Architecture
- **Framework**: Vue.js 3 (Composition API, `<script setup>`)
- **Routing**: Vue Router 4 (HTML5 History Mode, smooth scroll restoration)
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS 3 (Custom executive luxury theme, glassmorphism, gold gradients)
- **Icons**: Lucide Vue Next
- **Fonts**: Outfit (Headings), Plus Jakarta Sans (Body), Playfair Display (Quotes)

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Production Build
```bash
npm run build
```
Generates production-optimized static bundles in `dist/`.

### 3. Preview Production Build
```bash
npm run preview
```
